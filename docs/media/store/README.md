# Store assets (v0.44.0)

Curated Chrome Web Store screenshots, captured from a live colonist.io game on
v0.44.0. All shots are 1280x800 (the CWS screenshot size). Real HUD, not
streamer mode.

| File | CWS slot | Shows |
| --- | --- | --- |
| `01-opening.png` | Screenshot 1 | Board-affinity headline plus the ranked opening-pick list (A/B/C/D settle options with scores and tiles). |
| `02-strategy.png` | Screenshot 2 | Active Ore-Wheat-Sheep archetype with the strategy ranking and a scored recommendations list (city / port builds). |
| `03-robber.png` | Screenshot 3 | Ranked robber targets with steal-value badges, robber live on the board. |
| `04-devtiming.png` | Screenshot 4 | Dev-card play-timing hint: "1 knight from Largest Army, play it for +2 VP". |
| `05-winning.png` | Screenshot 5 | Late-game dominant position, 12 VP and leading, advisor fully populated. |
| `victory.png` | spare | The colonist Victory screen with the HUD at 13 VP. Busier composition; kept as an alternate. |
| `demo-hud.gif` | promo / social | ~12s loop of the side-panel re-ranking live (704K). |

Promo tile for the CWS listing header lives at `../promo-tile-440x280.png`.

Source frames and the extraction pipeline stay in the gitignored `dist/` tree.
