C CatanBot v0.44.1 · 2026-06-03

A live Catan advisor that watches the game with you.

Chrome side-panel HUD plus a local Python bridge that ingests every WebSocket frame from colonist.io, runs a handcrafted recommender with dev-card hints and robber EV on top of catanatron, and renders the verdict in real time. No ML, no cloud. Your game state never leaves your machine.

Install

You need both pieces for the full advisor: the Chrome extension renders the HUD, the bridge does the heavy lifting. The extension alone works too, with a leaner standalone engine.

Chrome extension

stable v0.44.1 ~177 KB

Side-panel HUD on the right of every colonist.io tab. Manifest V3, no Tampermonkey. Ships a standalone JS recommender so it runs with zero install (experimental, reduced accuracy); add the bridge below for full-accuracy recs. A one-click Chrome Web Store install is on the way (listing submitted for review).

  • Download the latest release zip and extract it.
  • Open chrome://extensions, toggle Developer mode.
  • Load unpacked → pick the extracted extension/ folder.
  • Pin the icon, click it, open colonist.io.

Local bridge (Python)

optional v0.44.1 FastAPI

Unlocks 1-ply search-delta annotations, postmortem rendering, eval sparkline, move-quality grading, and trade evaluation. Runs locally on 127.0.0.1:8765.

git clone https://github.com/NoahLaforet/CatanBot.git
cd CatanBot
./bin/catanbot live

First run auto-creates a .venv and installs the bridge in about 30 s. Needs Python 3.11+. Windows users: clone the repo, then double-click bin\setup-windows.cmd to install WSL2 + Ubuntu and bootstrap the bridge inside it.

What it does

Live recs and verdicts

  • Opening picks. Every legal corner ranked by complement-aware production, port adjacency, distance-2 denial, and resource diversity. Pairs each pick with a follow-up road suggestion.
  • In-game recommender. Top-N ranked actions: settlement, city, road, dev card, port trade. Each rec carries a 1-ply EV delta when the bridge is running so you see how much better the bot's pick is than doing nothing.
  • Dev-card play timing. Knight, monopoly, year-of-plenty, and road-building each get a typed PLAY/HOLD verdict with plain-language reasoning. VP cards are tracked but not surfaced as playable. Catan's no-play-on-buy rule is respected.
  • Robber and 7-roll telemetry. Top targets ranked by blocking value, victim VP, and hand size. Auto-detects colonist's optional Friendly Robber rule and filters protected (2-VP-or-under) victims.
  • Incoming trades. An opponent's offer gets an ACCEPT / DECLINE / CONSIDER verdict with the reason, so you are not eyeballing whether a swap helps them more than you.

Strategy-aware

  • Five archetypes. Ore-Wheat-Sheep, Longest Road rush, Port trader, Road Builder, Balanced. Once both opening settles land, the bot detects which archetype your placements actually enable and biases recommendations toward it.
  • Pivot triggers. Hot-number streaks, road-building dev card drawn, an opp closing on Largest Army, an opp crossing close-to-win VP, sevens overdue with a heavy hand. Each fires a named trigger that adapts the bias mid-game.
  • Backed by data. Several tunings in the recommender are inspired by u/Hot-Rooster1675's 36k-game simulation, including 3rd-settle expansion bumps and wheat-priority weights.

HUD details

  • Live overlay. Roll histogram with a 36-roll baseline, eval sparkline, per-build move-quality (!! / ! / ?! / ? / ??), opp hand inference, and production rate.
  • Variant boards. Same Catan rules, different layouts: the Pond and Twirl maps, the Gold Rush fog board, and the Volcano gold-and-fog map all build a fresh CatanMap from colonist's authoritative geometry.
  • Streamer mode. Every opponent username in the HUD is swapped for a neutral fantasy name (Aria, Bram, ...) before colonist's first paint, so screen recordings never expose real handles.

Privacy

The bridge runs locally. Game state never leaves your machine. The Chrome extension's only network destination is 127.0.0.1:8765, the bridge listening on localhost only, and the extension's host_permissions in manifest.json reflects that. Full privacy policy: privacy.html.
